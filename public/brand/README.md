# Visa Pass Migration brand assets

This folder stores Visa Pass Migration brand/logo assets for use in the app.

Expected files:
- vpm-logo-dark.png
- vpm-logo-light.png
- vpm-logo-icon.png
- vpm-logo-with-slogan.png

Logo usage should follow the Visa Pass Migration brand guidelines:
- preserve clear space
- do not stretch, skew, recolour, outline, or add drop shadow
- use correct contrast logo versions for dark/light backgrounds
